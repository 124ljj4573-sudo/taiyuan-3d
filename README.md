# 明清太原府城 · 3D 示意模型

打开方式：直接双击 `taiyuan-fucheng-3d.html`（单文件、约 0.6MB、无需联网，three.js 已内联）。
操作：左键旋转，右键平移，滚轮缩放；悬停看名称，点击建筑/城门/标签看介绍；底部按钮可切换鸟瞰、俯视、城南望迎泽门、西北角、大南门街街景、晋王府、双塔寺视角，也可自动旋转、隐藏标签、隐藏城外坛庙。
重新生成：`npm install && node build.mjs`（源码在 src/，史料数据在 src/data.js）。

## 资料依据（有出处的部分）
- 洪武九年（1376）永平侯谢成展筑东、南、北三面；周二十四里，高三丈五尺，外包砖，池深三丈；八门：东宜春、迎晖，南迎泽、承恩，西阜成（一说“阜城”）、振武，北镇远、拱极；俗称：大东门、小东门、大南门、新南门（首义门）、旱西门、水西门、大北门、小北门。城范围大致东建设路、西新建路、南迎泽大街、北北大街。来源：万历《太原府志》转引、百度百科“太原府城”、太原日报 2024 旅发大会报道、腾讯新闻《老太原城御洪记》、tydao.com《太原城墙记忆》。
- 城墙周长约12公里、高约12米、上宽6–10米、底宽约15米、每百余米设马面、四角楼、各门有瓮城（拱极门现存瓮城）。
- 布局：鼓楼为全城中心，钟楼偏东南；东北为晋王府（宫城开东/西/南华门，外有四面萧墙）；鼓楼以北为官衙区；东南为文化区（府儒学、贡院、书院、考棚）；南关一带为工商区；西部有卫所；城外东有先农坛、西有河神庙、北有社稷坛厉坛、南有神祇坛；北关、南关有关城。来源：《中国城市历史地理》“明清太原城”。
- 主干街：大北门街（镇远门）、大南门街（迎泽门，直抵黑虎庙）、水西门大街（与大南门街在城区西南十字相交）、旱西门大街、新南门大街。东西、南北之间无直通大街。
- 晋王府：清顺治三年（1646）火毁；肖墙街、东/西/南华门街等地名遗存。来源：太原历史文化街区系列（tydao.com）、太原日报。
- 崇善寺：洪武十四年扩建，同治三年（1864）火毁，光绪八年（1882）张之洞在前部遗址改建文庙。来源：维基百科“崇善寺”。
- 永祚寺（双塔寺）：东塔文峰塔 1599 年、西塔宣文塔 1608–1612 年，均八角十三层，约54.76/54.78米，两塔相距46米，位于府城外东南约3公里郝庄岗上。来源：维基百科“永祚寺”、中新网、太原日报。

## 哪些是示意/推测（模型中虚线标签＝位置示意）
- 城墙画成严格正方形、平均每边300米×10；实际形状并非正方，位置只对应“东建设路/西新建路”等大致范围。
- 墙高为便于观看放大约2倍；门楼、角楼、瓮城、马面数量与形制均为示意；双塔放大约3倍。
- 护城河宽度、走向为示意；汾河河道与距离为示意。
- 各衙署（府治、布政司、按察司、贡院）、钟鼓楼、纯阳宫、各坛庙的具体坐标为示意，只保证相对方位（如“钟楼在东南”）。
- 晋王府内部殿宇布局为示意；宫城“北面不设门”一说与另有文献所载“后宰门”不一致，模型按《中国城市历史地理》画法。
- 民居、树、远山完全是装饰性的程序生成，不代表真实街巷肌理；街巷网格只有文献明确提到的主干街是依据史料画的。
- 未包含：清顺治六年所筑满城（位置与范围资料不足）、城内各条小街巷名。
